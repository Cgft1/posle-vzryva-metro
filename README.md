# После взрыва: Метро

Minecraft Forge 1.20.1 (47.2.0), Java 17.

## Что есть в прототипе
- Предметы: металлолом, проволока, пружина и фильтр.
- Противогаз: положи его в слот шлема, чтобы не получать эффект радиации.
- Самодельный пистолет и дробовик: прототип оружия с атакой по направлению взгляда.
- На открытой поверхности выше Y=100 без противогаза игрок получает эффекты от радиации.

Это ранний прототип: генерация метро, монстры, рецепты, текстуры и расход фильтра ещё не реализованы.

## Скачать мод
После успешной сборки открой вкладку Actions, выбери последний успешный запуск `Build Minecraft mod` и скачай артефакт `posle-vzryva-metro-jar`.
